# IMC Prosperity 4 Leaderboard

[![Build](https://github.com/PGuffey/imc-prosperity-4-leaderboard/actions/workflows/deploy.yml/badge.svg)](https://github.com/PGuffey/imc-prosperity-4-leaderboard/actions/workflows/deploy.yml)

An alternative leaderboard viewer for IMC Prosperity 4.

Live site: https://pguffey.github.io/imc-prosperity-4-leaderboard/

## Credits

This project is based on the work of [jmerle](https://github.com/jmerle), specifically his [IMC Prosperity 3 Leaderboard](https://github.com/jmerle/imc-prosperity-3-leaderboard), which itself builds on his earlier Prosperity leaderboard viewers.

This version adapts the architecture to the Prosperity 4 API, data format, and Phase 1 / Phase 2 competition structure.
